No public email address. The HUB does not publish an email inbox. The fastest route for anything below is a GitHub issue — it is public, searchable, and it is where bugs actually get fixed.

Support & bug reports

  • HUB site issues (broken link, wrong count, missing page): open an issue on the Portfolio repository — the HUB's published support route.
  • Plugin bugs (FreeEQ8, FreeVox8, Maid Suite, etc.): open an issue in that plugin's own repository — e.g. FreeEQ8 issues. Include your DAW, OS and plugin version.
  • Licences & Master Key seats (ProEQ8, $3 CAD/seat/month): use the licence tools on the Account page, or open a Portfolio issue.

Business, licensing & press

For licensing, distribution, collaboration or press enquiries, open a Portfolio issue with the subject line starting [Business] and describe what you need. There is no press kit yet — the About page and the Ecosystem Index are the current public sources on the project.

Privacy

How the HUB handles your data is described in the Privacy Policy. Privacy-related requests can also be raised as a Portfolio issue.
