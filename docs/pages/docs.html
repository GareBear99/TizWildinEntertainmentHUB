ARC-Core Architecture

The HUB's authority, entitlement, and release-polling backbone is ARC-Core — a deterministic event/receipt/authority kernel. Every entitlement, activation, update, and billing transaction is replayable, tamper-evident, and SHA-256 addressable.

ARC API Reference

FastAPI backend (arc_service) providing auth, entitlements, billing, release management, install plans, and SoundCloud OAuth. Run locally with Docker or directly.

🔗 Key Endpoints
GET /health — Server health check
POST /auth/soundcloud/callback — SoundCloud OAuth code exchange
GET /auth/soundcloud/follow-status — Check TizWildin follow status
POST /auth/login — Email/password login
GET /catalog — Product catalog
POST /billing/checkout-session — Stripe checkout
