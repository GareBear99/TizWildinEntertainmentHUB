ARC-Core Architecture

The HUB's authority, entitlement, and release-polling backbone is ARC-Core — a deterministic event/receipt/authority kernel. Every entitlement, activation, update, and billing transaction is replayable, tamper-evident, and SHA-256 addressable.

Account & Linked Platforms

Sign in with SoundCloud or Google. Link your SoundCloud, Spotify, and GitHub to submit songs to the 24/7 radio. Get 3 songs accepted through the quality gate to earn a ✅ Verified badge on the HUB.

🔑 Account Page 🔊 SoundCloud 🎵 Spotify 🐙 GitHub
✅ Verified Badge: Submit songs to the 24/7 radio via SoundCloud or Spotify URL. Each submission is quality-gated using FreeEQ8-style analysis (EBU R128 loudness, clipping, bitrate, duration). After 3 accepted songs, your account is automatically verified on the HUB.
📻

24/7 Radio Stream & Song Submissions

Dockerized radio service streaming to YouTube via FFmpeg RTMP. Default playlist pulled from your SoundCloud. Users submit songs via SoundCloud/Spotify URL — quality-gated with FreeEQ8-style analysis before queuing.

POST /radio/submit — Submit song via SoundCloud/Spotify URL (auth required)
GET /radio/queue — Current queue status + pending submissions
GET /radio/history — Recent play history
GET /account/verified — Check verified badge status (3 accepted = verified)
🎧 Quality Gate: EBU R128 loudness (≥-30 LUFS), true peak (≤-0.5 dBTP), bitrate (≥96kbps), duration (≥30s), silence detection. Score ≥50 + no critical issues = accepted.

Backend API Reference

Cloudflare Worker backend (tizwildin-hub.admension.workers.dev) handling authentication, licensing, subscriptions, and community features for all TizWildin products.

🔑 Core Endpoints
POST /auth/google/signin — Google OAuth sign-in with geodata tracking
POST /activate — Activate ProEQ8 license on device
POST /hub/master-key/link — Link seat to email (Master Key)
GET /hub/account — Full account status + licenses
POST /create-checkout — Stripe checkout for ProEQ8
GET /hub/community-stats — Community statistics
